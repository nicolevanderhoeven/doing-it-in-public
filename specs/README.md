# Specs

Every chapter has a folder here. Each folder contains the intent, design, and task documents that shaped the chapter — committed alongside the content so readers can see what each chapter was trying to do before seeing what it became.

See [PROCESS.md](../PROCESS.md) for how this system works.

## Structure

```
specs/
├── book/          ← whole-book intent and working outline
└── chapters/
    ├── introduction/
    ├── chapter-01/
    ├── chapter-02-what-ai-changes/
    └── ...
```

## Files in each chapter folder

| File | Written by | Purpose |
|------|-----------|---------|
| `intent.md` | Nicole | What this chapter argues. Set before drafting. |
| `design.md` | Iris | Proposed structure and sources. Generated after intent. |
| `tasks.md` | Both | What still needs doing. Updated as work progresses. |
